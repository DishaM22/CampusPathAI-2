How to read this: `repeat_last` = guess the same category / club as the student's previous interaction; `popularity` = guess the most frequent in training; `chance` = random guess; `markov` (recommendation question only) = a lookup table of what students engaged with after an event of the previous event's category / club, blended with popularity.
A model that does not clearly beat `popularity` and `markov` on the RECOMMENDATION question has not learned anything useful for recommending.

The next-interaction questions are easy to game: a student's view, save, register and attend of one event all share its category and club, so copying the previous interaction already looks almost perfect. The RECOMMENDATION question removes the student's earlier steps on the same event from the history, which is what the live recommender will face. Judge the model on that one.
